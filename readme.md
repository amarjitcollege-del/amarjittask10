#  Laundry Wallah

A modern and responsive laundry service website built using **HTML and CSS**. The website features an animated hero section with an orbiting washing machine, squash-and-stretch animation, service cards, an about section, and a contact section.

## Project Overview

**Laundry Wallah** is a professional laundry service landing page designed to provide a clean, modern, and visually attractive user experience.

The main focus of the project is the animated hero section, where the washing machine moves along an orbital path while rotating and changing its shape using non-uniform scaling.

## Features

* Responsive navigation bar
* Professional laundry service branding
* Animated hero section
* Washing machine orbital animation
* Squash and stretch animation
* Rotating washing machine drum
* Animated orbit rings
* Floating laundry basket
* Floating soap elements
* Animated sparkle effects
* Service cards
* About section
* Contact section
* Responsive desktop, tablet, and mobile layouts
* Smooth scrolling navigation
* Hover effects and transitions

## Animation Requirements

This project specifically demonstrates two important CSS animation techniques.

### 1. Orbital Movement

The washing machine follows a simulated orbital path using multiple `translate()` transformations.
